# Pharos Ledger

Live: https://pharos-ledger.vercel.app

Audit log, weekly digest, and a read-only portfolio Q&A for a wallet on Pharos Pacific. Official Chain MCP. Portfolio reads FaroSwap V3 LPs, Faroo, Harbor Axil, Morpho, TermMax, and live Prosper vaults.

```bash
npm install
npm test
npm run audit -- 0x912c9aDe24D44d8922f0866D8Dcb079f1363f647
npm run digest -- 0x912c9aDe24D44d8922f0866D8Dcb079f1363f647
npm run portfolio -- 0x912c9aDe24D44d8922f0866D8Dcb079f1363f647 "where is my USDC?"
npm run web
```
