# Portfolio Assistant

Ask a wallet a plain question. The page reads official-token balances, extra ERC-20s, FaroSwap V3 NFTs, Faroo stPROS vaults, Harbor Axil Prime (APC3M) and Axil Pot (APT), Morpho mmUSDC / SharpByte, TermMax tmseUSDC + sbPharosPrime, and the live Prosper vault + p{VAULT} list from api.pros-per.xyz. Figures cite contract + block. No marketing APY from Port.

Zona, Ember, Asseto, Agra, NewSight, Grandline, PNS/ZNS, OKU-as-UI, InterPort, LayerZero, Bifrost, and the rest of the Harbor catalog stay unread until a Pacific share token is public.

Read-only. Chain MCP. `eth_call` / `balanceOf` / `tokenOfOwnerByIndex` / `positions` / `allowance` / `get_balance`. No swaps.

```bash
npm run portfolio -- 0x912c9aDe24D44d8922f0866D8Dcb079f1363f647 "where is my USDC?"
```

Live: https://pharos-ledger.vercel.app/#portfolio
